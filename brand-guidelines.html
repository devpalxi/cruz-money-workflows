Section 12

Anti-Patterns

Design rules that must never be violated. These are the most common mistakes that break the premium feel.

block Never use linear or ease-in-out easing — always --spring or --snap
block Never use pure black shadows rgba(0,0,0,x) — always tint to match component hue
block Never use browser default fonts — always load Outfit / Hanken Grotesk / Inter explicitly
block Never use flat untextured backgrounds — the noise grain overlay is mandatory
block Never create buttons shorter than 44px — accessibility minimum (WCAG 2.5.8)
block Never use generic rounded circles for avatars — use 12px squircle border-radius
